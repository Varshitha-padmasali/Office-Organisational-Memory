# API Reference

Full interactive docs are auto-generated by FastAPI and available at
`http://localhost:8000/docs` (Swagger UI) or `/redoc` whenever the backend
is running — that's the source of truth. This file is a quick human-readable
summary.

## Unversioned (infrastructure)

| Method | Path      | Status        | Description                              |
|--------|-----------|---------------|-------------------------------------------|
| GET    | `/`       | ✅ Implemented | API metadata / links to docs & health     |
| GET    | `/health` | ✅ Implemented | Liveness + Postgres connectivity check    |

Every stub returns a consistent error shape:

```json
{
  "error": {
    "message": "Documents endpoints are not implemented yet. Planned for Day 2-3.",
    "status_code": 501
  }
}
```

This is the same shape any real error uses (see `app/main.py`'s exception
handlers), so frontend error handling doesn't need special-casing.
